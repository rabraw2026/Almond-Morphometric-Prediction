# Support Vector Regression (SVR) Analysis

This folder contains the dataset, Python code, model outputs, and figures associated with the Support Vector Regression (SVR) analysis.

The analysis evaluated linear, polynomial, and radial basis function (RBF) kernels for predicting kernel morphometric ratios (Ker_L/W, Ker_W/T, and Ker_L/T) from external fruit morphometric ratios (L/W, W/T, and L/T).

The folder includes:
- Python code used for the SVR analysis
- Dataset used for model training and testing
- SVR model results and hyperparameter optimization outputs
- Actual versus predicted plots
- Residual plots
- Permutation-based feature importance plots
- Fruit-to-kernel morphometric relationship plots
